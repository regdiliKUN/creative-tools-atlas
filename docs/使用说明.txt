创作工具星图 · 本地软件包（v2.1.0）
==========================================

【快速开始】
  双击本文件夹内的  创作工具星图.exe
  会以「应用窗口」方式打开应用首页（index.html）——无地址栏、无标签栏，
  观感像独立软件，而不是弹出一个浏览器页面。
  实现：优先调用本机 Edge / Chrome 的 --app 模式；若都没有则回退系统浏览器。

【应用内容】
  index.html                        应用导航首页
  github-creative-tools-atlas.html  报告一：GitHub 创作工具星图（4 大分类 / 23 个项目 / 3 条航线）
  route-a-painter-workstation.html  报告二：画师的数字工位（航线 A 实操手册）
  以上三个 HTML 互相链接，请保持在同一文件夹内。

【桌面快捷方式】
  已在桌面创建「创作工具星图」快捷方式，目标直接指向本文件夹内的 exe。
  右键该快捷方式 →「打开文件所在位置」，可定位到本文件夹并选中 exe。

  若快捷方式被误删，在本文件夹的「快捷方式工具」目录打开 PowerShell 执行：
    powershell -ExecutionPolicy Bypass -File rebuild-shortcut.ps1
  校验快捷方式指向：
    powershell -ExecutionPolicy Bypass -File rebuild-shortcut.ps1 -ReadBack
  校验软件包完整性（比对 MANIFEST.md）：
    powershell -ExecutionPolicy Bypass -File verify-package.ps1
  脚本会自动解析真实桌面（兼容重定向 / OneDrive），无需手工填路径。

【运行特性】
  · 内容本地可读、无需联网、不上传任何数据；报告内 GitHub 外链仅在点击时联网。
  · exe 是本地启动器（第二十轮起）：先确认本地工具桥在运行——没运行就在后台无窗口启动它，
    再用应用窗口打开 http://127.0.0.1:7843/。工具桥会常驻后台，只监听本机 127.0.0.1:7843；
    启动器本身打开窗口后即退出。关闭窗口后可立即再次双击打开（5 秒内连点会自动去重）。
  · 工具桥起不来时（例如本机没有 Python），会退回直接打开本地文件：报告照常能看，
    但工坊的「一键执行」需要工具桥，这时请双击「快捷方式工具\start-all.bat」排查。
  · 支持中文与空格路径（URL 已做编码处理）。
  · 若 index.html 意外缺失，会显示友好的诊断页（写在系统临时目录，不污染软件包）。
  · 若应用窗口未自动打开：手动双击 index.html 可获得完全相同的内容。
  · 关于内置浏览器：exe 是独立程序，无法调用 WorkBuddy 应用内部的内置浏览器
    （两者是不同进程）；内置浏览器仅用于在 WorkBuddy 中预览这些 HTML 文件。

【文件完整性】
  MANIFEST.md 记录了各文件的 SHA-256 校验基线（含全部迭代记录与工具脚本）。
  用「快捷方式工具/verify-package.ps1」可随时核对，输出 VERIFY_OK 即为完好。
  校验基线由构建脚本 build_manifest.py 生成；正常用户无需重新生成，
  仅当自行改动包内文件后，才需用该脚本刷新基线（脚本在使用者的构建环境中）。
  维护注意：快捷方式工具/ 下的 .ps1 脚本必须保持纯 ASCII 内容（中文请写进
  UTF-8 JSON 或用字符码拼接）。PowerShell 5.1 会按 ANSI 读取无 BOM 的 .ps1，
  混入中文会导致解析失败。

【本地工具桥】
  工坊的「启动 / 一键安装」按钮和「一键执行」都靠本地工具桥。正常情况下不用管它：
  双击 exe 或桌面快捷方式时会自动在后台启动。
  备用入口：双击「快捷方式工具\start-all.bat」，会启动工具桥并打开工坊，
  全过程记录在同目录的 start-all.log（排查问题时看它）。
  自动更新：工具桥的代码更新后，它会在没有作业运行时自己换成新版本
  （切换前会先在独立进程里试导入新代码，导入失败就不切换），页面也会自动重新连上。
  关闭：在「快捷方式工具」目录执行 powershell -ExecutionPolicy Bypass -File start-tool-bridge.ps1 -Stop
  （只关闭本工具的桥，不会误杀其他程序）。
  说明：该服务只监听 127.0.0.1:7843，且只接受本机来源；只有你点「下载模型」时才会联网。

【创作工坊 · 产出内容】
  双击首页的「创作工坊」卡片进入，或直接用浏览器打开 studio.html。

  工作流支线（v1.6.2 起）：
    ① 顶部选一条或多条工作流（角色立绘 / 三视图 / 基建重建基准图 / 图生3D /
       手办打印 / VRM / 像素动画 / CAD / PBR贴图），页面会切成对应独立支线；
    ② 每条支线只显示该需求所需的工具（按上下游顺序）、操作提示与避坑要点，
       无关工具收在「其他工具」折叠区里；
    ③ 点工具上的「启动」直接打开本机软件（需先运行 tool-bridge 工具桥），
       未装的显示「一键安装」；
    ④ 支线底部点「用这条工作流生成任务包」，展开参数区并预填，填好主体即可生成。

  一键执行（第十三～二十轮）：
    · 生成任务包后点执行台的「⚡ 一键自动执行任务包」，能自动的步骤由引擎完成，
      需要人的步骤会停下来，出现「轮到你了」卡片。ComfyUI 没开时引擎会自动启动它
      （关掉再开后，首次出图要先加载模型，可能要几分钟）。
    · 停在人工步骤时可以选后续方案：A 我在 Krita 里改 / B AI 自动精修（放大重绘 + 去背景）/
      C AI 在 Krita 里逐笔画（精细约 35 分钟 / 快速约 10 分钟）。做完还能接着选方案加工。
    · 角色立绘会自动出 4 张同一角色的变体，点「选这张」定稿。
    · 图生 3D、基建重建等需要现成图片 / 3D 模型的支线：执行台会出现「输入文件」，
      也可以在停下来的卡片里上传（图片 png/jpg/webp，模型 glb/gltf/obj/stl/fbx/ply，≤200MB）。
    · 出图模型：默认 SDXL 基础版；可在执行台一键下载 Animagine XL 4.0 Opt
      （插画 / 动漫角色，6.94GB，CreativeML Open RAIL++-M 可商用），下载完之前自动用基础版。
    · 中文提示词：出图模型读不懂中文，生成任务包后会显示「实际发给模型的英文提示词」，
      翻得不对可以直接改；首次使用需下载本地翻译模型（约 315MB，下载后不用联网）。
      中文写成逗号分开的短词（如：古风，汉服，少女，手持油纸伞）最准。
    · 页面刷新后，从「🗂 最近作业」里点「接着做」即可回到暂停的作业。
    · 出图明显变慢 / 卡住：先点执行台出图模型旁的「重启 ComfyUI」（有作业在跑时不能重启）。
      出图速度还取决于显卡有没有被别的程序占着：Ollama 本地大模型、模拟器（MuMu）、游戏等
      会抢显存和算力，出图前关掉它们会快很多（实测同一步从 90 多秒降到 1 秒以内）。
  Krita「Atlas 工坊」面板（第一次选方案 A 或 C 时在 Krita 关闭状态下自动安装）：
    分层打开（底层「AI 原图」锁定、上面「我的修改」）、AI 精修当前画布 → 新图层、
    AI 去背景 → 透明蒙版、改提示词、「✓ 完成，回传工坊」（不用回浏览器）。
    在 Krita 菜单「设置 → 面板 → Atlas 工坊」可以手动显示 / 隐藏。

  首次启动 Krita 若停在「正在加载资源」画面，是它在首次建立笔刷资源缓存，
  约 1–3 分钟属正常；缓存建好后（本机已建好，1043 个资源）再启动就快了。

  任务包内容（可复制 / 导出 .md）：
    · 结构化正面 / 负面提示词，可直接粘进 ComfyUI 或 Krita AI Diffusion
    · 三视图 / 重建基准图的 8 条硬规则与显存档位参数建议
    · 7 个生产环节的工具链，同功能优中选优（首选 / 备选及判断依据）
    · 分阶段执行清单、许可证与避坑提示、全部 52 个工具的索引
  显存不够或许可高风险的工具会被自动降级，并写进「适配提示」，不会让你白跑。
  任务包可「保存到本地」留存在浏览器里，随时载入或删除；所有输入仅在本机处理，
  不上传、不联网（工具链接仅在点击时才访问网络）。

【故障自查】
  若双击 exe 或桌面快捷方式没有反应，在「快捷方式工具」目录打开 PowerShell 执行：
    powershell -ExecutionPolicy Bypass -File diagnose.ps1
  它会依次检查：核心文件是否齐全、浏览器是否可用（缺失为警告，不影响回退）、
  桌面快捷方式是否精确指向本包 exe、_internal 运行依赖是否完整、
  MANIFEST 里登记的文件是否都未被改动。
  输出 DIAG_OK 表示一切正常；DIAG_FAIL 会点名问题并给出修复建议。

【卸载 / 移除】
  1. 删除桌面「创作工具星图」快捷方式。
  2. 删除整个「创作工具星图」文件夹即可，无注册表残留、无系统级安装。
