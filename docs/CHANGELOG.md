- 门禁：自检套件新增 3 组契约断言（数据 / 交互 / 桥端），把本轮修复固化为可重复验证的防线；8 处版本标记全量对齐。
- 详见 `迭代记录/迭代记录-v10.md`（逐轮目标 / 改动 / 理由 / 自检 + 整体提升 + 诚实排除说明）。
