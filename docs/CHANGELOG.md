## v1.6.0（2026-11-17，第六轮 20 轮迭代）

主题：从「手工打磨」到「自动化质量保障」。

- 新增 `selftest.py`（构建目录）：开发期自动化自检套件，7 组共 17 条断言，
  覆盖 HTML 结构、外链安全、无障碍、版本一致性、清单一致性/动态同步、
  `.ps1` 纯 ASCII、迭代档案轮次完整、诊断器自身完整性。支持 `--base` 对副本运行，
  并用故意植入缺陷的副本验证过套件有效性。
- 新增 `diagnose.ps1`（包内快捷方式工具）：用户侧一键故障诊断，纯 ASCII、零依赖，
  5 个检查点（核心文件 / 浏览器 / 快捷方式 / 运行依赖 / 完整性），
  分 OK-WARN-FAIL 三级并给出下一步指引；故障副本实测能点名缺失文件。
- MANIFEST 由 15 项扩至 18 项，补齐此前遗漏的三个工具脚本。
- 使用说明新增「故障自查」章节，修正「含三份迭代记录」的过时表述。

验证方式：本轮 HTML 验证全部经 WorkBuddy 内置浏览器预览，未运行 exe、未弹系统浏览器。

## v1.3.0（2026-11-17，第三轮 20 轮迭代）

启动器关键修复：
- **修复单实例锁误判**：exe 是「启动即退出」型，原 120 秒锁会挡住用户关闭窗口后的再次启动；TTL 降至 5 秒，仅防连点。
- 缺文件兜底页文件名改 ASCII，避免 ANSI 代码页环境写临时文件失败。
- 浏览器候选精简为 4 条绝对安装路径，去除依赖环境变量的脆弱动态路径。
- 清理包内残留临时 JSON，并把快捷方式脚本的配置改写入系统 TEMP，永久避免污染软件包。

内容与呈现：
- 修正首页离线措辞（报告内 GitHub 外链仅在点击时联网）。
- 54 个外链补 `rel="noopener noreferrer"`，防止 window.opener 反向操作。
- 两页筛选框增加 aria-live 播报匹配数，修复播报计数范围。
- 统一两报告「数据来源与口径」标题。

验证方式：本轮全部 HTML 验证均通过 WorkBuddy 内置浏览器预览完成，未运行 exe、未弹系统浏览器。
