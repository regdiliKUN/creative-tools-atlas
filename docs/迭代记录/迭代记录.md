# 创作工具星图 · 迭代记录

> 起始版本：v1.0.0（2026-11-17 首次交付）
> 目标：累计 20 轮迭代，围绕正确性、完整性、可读性、性能、边界情况、一致性六个质量维度做实质提升。
> 锁定项（全程不变）：exe 启动方式、I 盘落位 `I:\workbuddy\创作工具星图\`、桌面快捷方式精确指向 exe。

## 基线快照

- 包路径：`I:\workbuddy\创作工具星图\`
- 内容：`创作工具星图.exe`（1,828,993 B）、`_internal/`、3 个 HTML、`icon.png`、`使用说明.txt`、`快捷方式工具/`
- 桌面快捷方式：`D:\Desktop\创作工具星图.lnk` → `I:\workbuddy\创作工具星图\创作工具星图.exe`
- 已知问题：① 包内存在冗余 exe 副本 `创作工具星图/创作工具星图`（1.8MB）；② windowed 启动器 `print` 中文在 GBK 控制台乱码；③ `file://` URL 未对中文路径做 percent-encode；④ 缺文件兜底页写入包目录造成污染。

## 迭代日志

### 阶段一：正确性与健壮性

**轮 1 · 完整性/正确性** — 清除包内 1.8MB 冗余 exe 副本（组装时误带入的 `创作工具星图/创作工具星图`），移除空壳目录。
理由：冗余二进制增大分发体积并造成"哪个是真 exe"歧义。自检：目录已不存在、顶层清单干净、体积因 `_internal` 主导保持不变。[达成]

**轮 2 · 正确性** — 启动器 `file://` URL 改用 `urllib.parse.quote` 对中文/空格编码；去掉 windowed 模式下的中文 `print` 与无意义 `sleep(2)`。
理由：中文路径直拼 `file:///` 在部分浏览器失效；GBK 控制台 print 中文有异常风险。自检：py_compile 通过；中文路径输出 `file:///I:/workbuddy/%E5%88%9B.../index.html`；源码运行 EXIT=0 无输出。[达成]

**轮 3 · 一致性** — 用 PyInstaller 重建 exe 并替换包内 exe 与 `_internal`，使轮2改动真正落地。
理由：源码与产物必须一致。自检：新 exe 1,829,620 B（旧 1,828,993 B）；实测双击 EXIT=0、零 stdout（静默无乱码）。[达成]

**轮 4 · 一致性** — 核对三个 HTML 之间的相对链接。
自检：index→两份报告、route-a→总览 共 3 条链接，目标文件全部存在，无 404。[达成]

**轮 5 · 边界情况** — 验证缺文件兜底页不再污染软件包。
自检：临时移走 index.html 后运行 exe，EXIT=0；包目录无 `_missing.html`；兜底页正确生成于系统临时目录；index.html 已恢复。[达成]

**轮 6 · 正确性（构建期）** — 为启动器增加 `verify_package()` 自检钩子与 `--verify` 模式。
自检：完整包返回 `(True, [])`；缺文件包正确列出 3 个缺失文件。定位为构建期工具（windowed exe 无 stdout）。[达成]

**轮 7 · 性能** — 目标：裁剪 `_internal` 体积。分析：18MB 中 python313.dll(6MB)、libcrypto(8MB) 为 webbrowser/ssl 必需；`--exclude-module ssl` 有破坏回退链风险，20MB 体积可接受，故不做激进裁剪；进一步检查无 `.pyc`/metadata 缓存可清。
结论：本轮无安全的高价值优化点——按约定说明原因，未做凑数式改动。[说明]

### 阶段二：完整性与可读性

**轮 8 · 完整性** — 补充有效 `icon.ico`（73KB）入包，使图标资源独立可用。自检：ICO 头 `00000100` 有效。[达成]

**轮 9 · 完整性/一致性** — 生成 `MANIFEST.md`，记录 7 个核心文件的字节数与 SHA-256 基线。自检：清单生成；过程中发现并修复了 shell 反引号把 `_internal/` 当命令执行的 bug。[达成 + 捕获缺陷]

**轮 10 · 一致性** — 统一版本号：使用说明.txt 与 index.html 的 v1.0.0 → v1.1.0，与清单一致。自检：三处版本 grep 结果唯一为 v1.1.0。[达成]

**轮 11 · 完整性/一致性** — 用 Python 脚本 `build_manifest.py` 取代手工 shell 生成清单，覆盖 9 项文件（含快捷方式脚本）。自检：清单刷新，index.html 与使用说明.txt 校验值随轮10改动更新。[达成]

**轮 12 · 完整性/边界** — 为包内「快捷方式工具」增加一键重建脚本 `rebuild-shortcut.ps1`，自动解析真实桌面并重建/回读快捷方式。自检：首次运行暴露 PowerShell 5.1 中文脚本编码 bug → 改为纯 ASCII 源码 + char code 组装中文名 → 回读成功，TargetPath 精确指向 exe。[达成 + 捕获并修复缺陷]

**轮 13 · 可读性/完整性** — 重写 `使用说明.txt`：新增 v1.1.0 特性、一键重建命令、完整性校验说明、中文路径支持等。自检：5 个关键字段全部命中。[达成]

**轮 14 · 一致性/可读性** — 为两份报告各增加浮动「返回导航首页」按钮，使首页↔两报告形成三页闭环导航。自检：两页各 1 处 `href="index.html"`。[达成]

### 阶段三：边界情况、性能、一致性与终检

**轮 15 · 一致性** — 最终重建 exe，使包内产物与含 `--verify` 的源码一致。过程：后台重建因 `set -e` 静默中断（未破坏产物，实测旧 exe 仍 EXIT=0）→ 改前台重建成功，新 exe 1,830,224 B。自检：新 exe 实跑 EXIT=0、大小与源码版本匹配。[达成，含一次失败诊断与恢复]

**轮 16 · 正确性** — 三份 HTML 结构校验（DOCTYPE / charset / html/body/script/style 标签配对 / 导航按钮）。自检：三页全部 PASS。[达成]

**轮 17 · 边界情况** — 实测一键重建快捷方式全流程（非仅回读）。自检：CREATED=1/EXPECTED=1，回读 TargetPath 精确指向 exe。[达成]

**轮 18 · 一致性** — 因轮14/15/12/13 改动导致校验基线过期，最终刷新 MANIFEST。自检：清单 exe 大小 1,830,224 与实盘一致。[达成]

**轮 19 · 完整性/正确性** — 新增 `verify-package.ps1`（纯 ASCII），把静态清单升级为可执行的完整性校验器。自检：CHECKED=9、VERIFY_OK、EXIT=0。[达成]

**轮 20 · 完整性/一致性** — 使用说明补充完整性校验命令；刷新清单；全量终检。
自检：① 9 项核心文件齐全；② exe 实跑 EXIT=0；③ 三页 HTML 结构完整；④ 完整性校验 VERIFY_OK；⑤ 快捷方式回读 TargetPath 精确。[达成]
