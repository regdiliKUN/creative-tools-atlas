# 创作工具星图 · 第三轮迭代记录（v1.2.0 → v1.3.0）

> 基线：v1.2.0（第二轮 20 轮迭代后的版本）
> 约束：验证不运行 exe、不弹系统浏览器，全部用 WorkBuddy 内置浏览器预览 HTML。
> 锁定项：exe 启动方式、I 盘落位 `I:\workbuddy\创作工具星图\`、桌面快捷方式精确指向 exe。

## 本轮侦察发现（待修的真实缺陷）

1. **单实例锁逻辑缺陷（严重）**：exe 是"启动即退出"型（Popen 后立刻返回），锁 TTL=120 秒且写 PID；用户关闭应用窗口后 120 秒内再次双击会被误判为重复实例 → 打不开应用。
2. **临时 JSON 残留**：`快捷方式工具/_rebuild-config.json`、`_readback-config.json` 是实测脚本时遗留在交付包里的临时文件。
3. **兜底页中文文件名**：系统临时目录下用中文名，个别编码环境有隐患。
4. **浏览器探测不全**：未覆盖 Chrome 用户级安装路径。

## 迭代日志

### 阶段 A：启动器时序与清洁性（轮 1-7）

**轮 1 · 正确性（本轮最关键）** — 修复单实例锁误判。根因：exe 是「启动即退出」型（Popen 后立刻 return，进程存活 <1 秒），但锁 TTL=120 秒且写 PID，导致用户关闭应用窗口后 120 秒内再次双击被误判为重复实例、打不开。改动：TTL 120 → 5 秒（仅防连点），并在注释里固化「启动器秒退、不可用长 TTL 锁」的约束。
自检：首次 True、2 秒内连点 False、6 秒后重开 True（关键修复点全部符合预期），编译通过。[达成]

**轮 2 · 完整性** — 清除包内残留的 `_rebuild-config.json` / `_readback-config.json`（上轮实测脚本遗留），并从根本修复：把 `rebuild-shortcut.ps1` 的配置写入路径由脚本目录（包内）改为 `$env:TEMP`。
自检：运行修改后的脚本，快捷方式重建/回读正常；包内临时 JSON 数量 0，配置文件正确出现在系统 TEMP。[达成 + 根治]

**轮 3 · 边界情况** — 缺文件兜底页文件名由中文 `创作工具星图_文件缺失.html` 改为 ASCII `creator-atlas-missing.html`，避免 ANSI 代码页环境下写临时文件失败。
自检：编译通过、文件名全 ASCII。[达成]

**轮 4 · 完整性/健壮性** — 浏览器候选精简为 4 条绝对安装路径，移除依赖环境变量的 `LOCALAPPDATA` 动态拼路径（冻结 exe 里环境变量可能缺失，拼出相对路径不可靠）；顺带清掉元组里从未使用的第二项，简化数据结构。
自检：4 条全为绝对路径、本机探测到 2 条可用、编译通过。[达成]

**轮 5 · 正确性（含自我纠错）** — 尝试让 webbrowser 回退依据返回值判断是否继续，随即发现这会引入 bug：Windows 上 `webbrowser.open` 成功时也常返回 `None`，`if None` 会误判失败、多开一个窗口。立即回滚，并把该陷阱写成注释固化。
自检：断言回退逻辑为「不抛异常即成功」、陷阱注释存在、编译通过。[达成 + 避免引入缺陷]

**轮 6 · 一致性** — 前台重建 exe（1,831,655 B）使源码改动落地；全程不运行 exe。
自检：包内 exe 与 dist 产物字节一致（cmp 通过）。[达成]

**轮 7 · 一致性** — 版本 v1.2.0 → v1.3.0；发现 MANIFEST 里残留 v1.1.0，根因是生成脚本 `build_manifest.py` 硬编码旧版本，故改脚本而非改生成物，再重新生成。
自检：三处版本 grep 唯一为 v1.3.0。[达成 + 根治]
