### assimp 补丁说明（重要）
`pip install pyassimp` 只装 Python 绑定，不含底层 `assimp.dll`，导致 import 失败、状态检测不过。
已从 assimp 官方 GitHub release（v6.0.6 windows-x64）下载 `assimp-vc145-mt.dll`，
复制到 `...\site-packages\pyassimp\assimp.dll`，import 已通过。
> 若某天 pyassimp 升级后失效，重做此步即可（DLL 需含 `aiImportFile`/`aiExportSceneToBlob` 等导出函数；
> Substance Painter 自带的旧版 assimp.dll 缺函数，不能用）。

## 四、ComfyUI 安装详情（踩坑最多，重点记录）

- 安装位置：`C:\ComfyUI`
- Python：**3.12.3**（`C:\Users\xukunhang\AppData\Local\Programs\Python\Python312\python.exe`）
  - 必须用 3.12！系统 Python 3.14 **没有 PyTorch CUDA wheel**，原 `install-comfyui.ps1` 用 3.14+cu121 会失败。
  - 本项目已提供修正脚本 `install-comfyui-v312.ps1`（但 torch 大文件下载极慢，实际用缓存离线装成，见下）。
- venv：`C:\ComfyUI\venv`
- 实际版本组合（已验证 GPU 可用）：
  - torch **2.7.1+cu128**
  - torchvision **0.22.1+cu128**
  - torchaudio：因无匹配 cu128 版，已移至 `C:\ComfyUI\_quarantine`（ComfyUI 文生图/图生3D 不需要）
  - torch 2.6.0+cu124 曾试用，但 `comfy-kitchen 0.2.41` 要求 torch≥2.7（其 custom_op 用了 `list[int]` 标注），启动报错，故升级到 2.7.1。
- 启动：`C:\ComfyUI\run_nvidia_gpu.bat`（调用 3.12 venv 的 python main.py --gpu-only --enable-manager）
- Web UI：`http://127.0.0.1:8188`
- 自动化引擎联动：桥 `/api/engine` 返回 `comfy_online=true`。

### 下载踩坑
PyTorch 官方 CDN 的 torch 包（2.4GB）在本机下载极慢/停滞（20 分钟未完成）。
最终解法：uv 缓存里已有完整的 torch 2.7.1+cu128 解包目录（`AppData\Local\uv\cache\archive-v0\`），
直接用 `shutil.copytree(dirs_exist_ok=True)` 把缓存中的 `torch/` `torchvision/` 覆盖进 venv 的 site-packages，
绕开下载，秒装成功。

### 遗留性能提示（非故障）
ComfyUI 新版提示「CUDA < 13.0 性能会很差」。当前 cu128 可正常运行 RTX 4090（计算能力 8.9）。
如需极致性能，可在网络良好时执行：
```
C:\ComfyUI\venv\Scripts\python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu130
```
（需 NVIDIA 驱动 ≥ 580，当前 621.14 已满足。）

## 五、唯一未完成项：Aseprite

- Aseprite 是商业软件（约 $19.99），winget 官方源无此包，本机未安装，无法合规自动安装。
- 三种获取方式（任选其一，需用户自行决定/付费）：
  1. Steam 购买：https://store.steampowered.com/app/359550/Aseprite/
  2. itch.io 购买：https://aseprite.org/
  3. 免费但需自行从 GPLv3 源码编译（功能相同，编译成本高，不推荐）
- 安装后把 exe 路径加入 `tool-bridge.py` 的 `TOOLS["aseprite"]["exe"]` 即可被状态检测识别。
- 免费替代（若不需要 Aseprite 特有功能）：LibreSprite / Piskel。
