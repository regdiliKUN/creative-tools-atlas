先看架构：四个项目其实是四层，不是四个软件

上一份星图里那一串名字，很容易被误读成"要装四套东西"——这是这条路线上最大的认知负担

实际情况是一条自上而下的调用链：你在 Krita 里画画，插件把你的选区、线稿、姿态翻译成条件，ComfyUI 在后台跑模型再把结果送回新图层。而 ControlNet 原始仓库只是这套技术的"论文与原型"，早已被 ComfyUI 和插件内置吸收，不需要安装、也不需要打开。

02

装机清单：先看显卡，再决定模型档位

官方 README 的硬指标是 NVIDIA ≥ 6 GB 显存；但 6 GB 和 12 GB 能跑的模型完全不是一回事

显存 / 硬件能舒服跑什么建议
6 GB（如 RTX 2060）SD 1.5 流畅、SDXL 可用；Illustrious 动漫向模型也很合适入门档。够用 优先选轻量模型，别一上来勾 Flux
8 GBSDXL / Illustrious 舒适，量化版 Flux（fp8）可试最主流档位，画师性价比最优
12 GB+Flux 2 / Z-Image 等大模型、多控制层叠加、高分辨率放大推荐 想长期做就按这个配
AMD / Intel / AppleROCm（v1.51.0 起纳入托管安装）、XPU（Arc 8GB+）、MPS（Apple Silicon，macOS 14+）可用但生态兼容性与速度弱于 CUDA
纯 CPU能启动，官方原话 "very slow"不建议 只适合验证安装是否成功
磁盘别只留 10 GB。 官方说 10 GB 是下限、"50 GB+ 也不罕见"——插件会把 ComfyUI 本体、ControlNet / inpaint / CLIP Vision 等辅助模型、以及你勾选的主模型全部拉下来。第一次配置请留足空间和网络时间。

安装 Krita 5.2.0 或更新版本

Windows 必须用 krita.org 官网直装包，不要用 Microsoft Store / Steam 版；Linux 用 AppImage，不要用 Flatpak。这两条是官方安装文档专门点名的高频踩坑。

下载插件 ZIP（不要解压）

从 Releases 取最新包，当前为 v1.53.0。

导入并重启

Tools ▸ Scripts ▸ Import Python Plugin from File… 选中 ZIP → 确认启用 → 重启 Krita → 新建或打开文档 → Settings ▸ Dockers ▸ AI Image Generation 打开面板。

点 Configure，选后端

三种后端见下表。多数人选本地托管服务器，勾选显卡类型与想要的模型工作负载，插件自动下载并随版本更新后端。

先跑一张 512² 的小图验证链路

确认能出图、结果能落到新图层，再开始勾大模型。不要第一步就把 50 GB 模型全拉下来。

后端选项适合谁代价
本地托管服务器有可用显卡、不想折腾的绝大多数人免费；首次下载耗时耗盘 首选
自定义 ComfyUI已有 ComfyUI、想复用模型 / 接远程 GPU 工作站、要用自定义节点图免费；需按 docs.interstice.cloud/comfyui-setup 装齐依赖
interstice.cloud没独显，或想先试试再决定要不要投硬件按量付费，作者用它支撑项目开发
03

四把刷子：插件真正改变工作方式的地方

不是"更好看的抽卡机"，而是把生成限制在你指定的地方、按你给的结构来

README 里那句设计目标值得反复读："从文字生成整张图是不可预测的；要得到你脑中的结果，就得把生成限制在选区内、用可变的强度细化已有内容、把文字聚焦到图像区域、并用参考图 / 草图 / 线稿 / 深度图来引导。" 下面四把刷子就是这句话的落地。

TOOL 01

选区生成 Inpainting

画师最常用的一把：圈一块地方，只改这一块，其余像素不动。
  • Fill：强度 100% 时的默认动作，选区内容按提示词重生成，并向周边颜色靠拢
  • Add Content / Remove Content：加物件 / 无提示词抹除物体并自动延续背景
  • Expand：扩画布补背景，构图从竖图改横图特别好用
  • 快捷键 Shift+Enter 生成；结果进 History，挑中再 Apply 成新图层
工作流意义 生成结果永远是独立图层，可反复退回与手绘覆盖
TOOL 02

实时绘画 Live Painting

你每画几笔，AI 就实时重解释整张画布，立刻看到"成片方向"。
  • 适合起稿阶段：随手几根色块，就能判断这个配色 / 构图值不值得深入
  • 社区经验强度 0.6–0.8：既保留笔触，又给 AI 补充空间
  • 配合 Job Queue：排队生成时你可以继续画，不用盯着进度条
注意 这是探索工具，不是精修工具；定稿仍要关掉它手工收
TOOL 03

控制层 Control Layers

ControlNet 被做成"图层"——你画什么条件，AI 就长什么样，而不是抽卡。
  • Scribble / Line art / Canny：涂鸦、线稿、边缘 → 线稿上色、保持造型
  • Pose：可编辑骨骼关键点，直接摆角色动作，不用重画
  • Depth / Normals：空间层次与体积，做场景透视和光照方向
  • Segmentation：色块分区指定"这里是天空 / 这里是衣服"
这就是 ControlNet 原仓库不用装 的原因：能力已在这里
TOOL 04

区域提示词 + 参考图

Regions 给不同图层 / 区域各写各的提示词；IP-Adapter 用图而不是文字来定风格。
  • Regions：左边人物、右边背景、上方天空，各写各的，互不串味
  • IP-Adapter：参考图做风格 / 构图迁移，甚至换脸；对系列作品统一画风极其关键
  • Edit Models：直接用一句自然语言指令改图（"把白天改成夜景"）
  • Upscale：分块放大到 4K / 8K 而不爆显存，细节同步增强
进阶 自定义预设可挂自己的 checkpoint、LoRA、采样器
一条从草图到成品的实操走法： ① 新建 1024² 画布，手绘线稿单独一层 → ② 挂 Line art 控制层锁造型 → ③ 开 Live Painting 快速试 3–4 个配色方向 → ④ 关掉实时，用 Regions 把人物 / 服装 / 背景分开写提示词 → ⑤ 圈选区 Fill 逐个精修手部、脸部、配饰 → ⑥ Upscale 出终稿 → 全程保留原始线稿层，任何一步都能回退。
04

关键交付物：三视图，以及一个反直觉的冲突

路线 A 之所以值得先走，是因为它产出的图能直接喂给路线 B 的图生 3D——但标准正好相反

画师被训练成要画出好看的图：戏剧性光影、氛围、投影、背景、飘动的头发。而图生 3D 模型要的是可重建的图：平光、白底、无投影、单对象、轮廓完整、细长结构越少越好。这不是谁对谁错，是同一个工位必须产出两套图。

Track 1 · For humans

美术设定图 / 展示用

给人看、给客户看、给自己的画集用。目标是"好看"与"表达"。

  • 可以有氛围光、投影、背景、景深
  • 可以有多角色、道具、文字标注、装饰边框
  • 可以强调质感与笔触，允许夸张透视
  • 输出：PNG / PSD，用于展示与提案
注意：这类图拿去生 3D，高光会被烘焙成假纹理，背景和影子会被当成几何体。
Track 2 · For reconstruction

重建基准图 / 喂给模型用

给 Hunyuan3D、TripoSR、TRELLIS 这类单图 / 多视图重建模型用。目标是"信息干净"。

  • 纯白或透明背景，无投影、无地面
  • 均匀平光，主体居中且完整不裁切
  • 一图一物，避免遮挡与细长结构
  • 正面 / 侧面 / 背面尺寸一致、视角严格对齐
这才是路线 B 的输入。建议在 Krita 里单独存一套「重建版」图层组。

重建基准图的 8 条硬规则

综合 TripoSR / Hunyuan3D 与本地 3D 生成实践，属于跨模型通用的输入约束。

✓纯白或透明底，无投影、无地面平面。先做一次背景去除再重建。
✓均匀平光。硬光与高光会被烘焙进贴图，之后无法重新打光。
✓主体完整居中，边缘不裁切；分辨率 512² 起步、理想 1024² 以上。
✓一图一物。两个对象会被融合成一团；配件请单独出图、到 Blender 里再装。
✓3/4 侧视角优于正视图：正视图没有深度线索，轻微旋转更容易读出体积。
✓多视图上传严格按 正 → 侧 → 后 顺序，顺序错会导致左右翻转 / 肢体扭曲。
✕避开细长结构：发丝、飘带、锁链、网格、细剑——重建时几乎必然塌掉，留到 Blender 手工补。
✕别用文字 / logo / 复杂花纹做关键特征：小字会糊成污渍，对称件会略微不对称。

什么时候该下到 L2，亲自开 ComfyUI 搭三视图工作流

单张设定图在 Krita 里手绘就够了。但"同一个角色稳定出现在正 / 侧 / 背三个视角"是工程问题，需要一致性约束与批量出图——这时才值得打开节点图。

结构化提示词打底

核心标签：character sheet, multiple views, front view, side view, back view, full body, white background, consistent design；再把发型、瞳色、标志配饰、服装剪裁等不可变特征锚点逐项写死。负面词排除 text, logo, deformed。

用 ControlNet 锁构图与比例

预置一张标准三视图骨架图 / 深度图作为条件输入，强制三个视角按统一人体比例排列；换视角时只替换控制图，不换提示词。常用 OpenPose 与 Depth / Canny 两条线。

用参考图锁身份

三档方案见下表。轻量做法：把已确认的正面高清设定图送进 IP-Adapter FaceID 类节点作为全局参考，权重从 0.6 起试。最稳做法：20–30 张多角度图训一个小 LoRA，再用同一 LoRA 批量出三视图。

锁 Seed 微调，再净化输出

找到满意基底后锁定 Seed，只调 CFG / Denoise 做变体；生成后经抠图（Rembg / LaMa）、去水印、ColorMatch、FaceDetailer 处理，输出干净 PNG。这一步不能省——脏数据进重建流程等于埋雷。

人工收尾（永远不能省）

把所有视图并排，统一高光、接缝、花纹细节。AI 省的是"从 0 到 60 分"的时间，审美判断和细节统一仍然是人做的。

一致性方案成本稳定性 / 适合场景
IP-Adapter / FaceID零训练，即插即用中等；极端角度会漂。权重 0.6–0.8，>0.8 画面僵硬发糊、<0.5 锁不住脸
InstantID / PuLID零训练，多装几个节点较好；脸部保真更强，常与 IP-Adapter 叠用（一个管脸、一个管风格体态）
自训角色 LoRA20–30 张多角度图，微调约半小时最稳；系列化 / 量产 / 长期角色的正解，训练集里必须包含多角度
要亲手装 ComfyUI 节点时，认这几个仓库： comfyui_controlnet_aux（4.3k ★，2026-11 仍活跃，65 个预处理器：OpenPose / LineArt / DepthAnything / Canny…）、ComfyUI_IPAdapter_plus（6.17k ★，主分支约 2025-04 后停更，星数还在涨但代码已静默，属"高星暗星"）、同作者的 InstantID 1.8k / PuLID 911 / essentials 1.2k。注意：这些节点只在 L2 手动搭图时才需要；Krita 插件已把等价能力打包好了。
05

参数速查：官方口径与社区经验值分开看

下表中标注"经验值"的数字来自社区教程，是起点不是定律，务必按自己的模型微调

参数建议值作用与出处
强度 Strength100% = Fill官方：有选区时 100% 触发 Fill。经验分区：0–30% 微调 / 30–70% 风格转换 / 70–100% 大幅重绘
实时绘画强度0.6 – 0.8经验值：保住笔触又给 AI 发挥空间
IP-Adapter 权重0.6 – 0.8经验值：偏高过拟合、构图僵死；偏低变脸
ControlNet 权重0.4 – 1.2经验值：线稿类可高、姿态类宜低，需按控制层类型调
生成步数 Steps20 – 30经验值：快速预览用下限，定稿再提高
工作分辨率512 – 1024经验值：先小图试方向，再 Upscale 到 4K / 8K 出终稿（插件分块放大不爆显存）
Seed / CFG / Denoise先锁后调三视图一致性关键：锁定基底后只动 CFG 与 Denoise，不要三张图各抽各的
变体通配符{A|B|C}社区用法：一次生成多个配色 / 服装方案供挑选
最容易被忽略的两个功能：History 和 Job Queue。 前者保存每次结果与当时的提示词，可随时回溯对比；后者让你排队生成时继续画。这两个决定了它是"工作流"还是"抽卡器"。

避坑清单：照着排，能省掉第一个下午

多数问题不在模型质量，而在安装环境与版本细节

卡在 "Starting Server" 转圈
v1.52.0 升级后的已知连接 bug，v1.52.1 已修复。装最新版即可；若仍卡，查 Windows 防火墙是否拦了本地端口与 Python 环境路径。
插件装了却找不到面板
确认 Krita ≥ 5.2.0、ZIP 未解压、导入后已重启、且在"有文档打开"的状态下才去 Settings ▸ Dockers 勾选。
Windows Store / Steam 版 Krita
官方点名不兼容，改装 krita.org 直装包；Linux 同理弃 Flatpak、改 AppImage。
自定义 ComfyUI 连不上
插件要求特定扩展与模型齐备，按 docs.interstice.cloud/comfyui-setup 逐项核对；若 ComfyUI 已在 Krita 启动前运行，插件会自动尝试连接。拿不准就用托管安装。
一上手就勾 Flux / Z-Image
官方标注这类模型"相对大且慢，需要强力 GPU"。6 GB 卡请先跑 SD 1.5 / SDXL / Illustrious，确认链路通了再加大模型。
求助于 Krita 官方渠道
README 明确写着官方 Krita 渠道不受理此插件问题；去项目 GitHub Discussions / Discord / FAQ 页。
抠图 / 去背景很麻烦
装同作者的 krita-ai-tools，补上 AI 分割与对象选择；这正好也是产出"重建基准图"要用的功能。
照着高星节点仓库装
ControlNet 原仓库（34.1k ★）停更于 2024-02、ComfyUI_IPAdapter_plus（6.17k ★）约 2025-04 后静默、InstantMesh 停在 2024。先看 pushed_at 再 clone。
07

交接给路线 B：这套工位最终要交出什么

把 A 与"一张立绘 → 一尊手办"那条线接起来

路线 A 的终点不是一张漂亮插画，而是一套能驱动几何重建的干净角色基准图。只要第 ④ 节的 8 条规则守住，下游几乎不用返工；反之，再强的 3D 模型也救不回一张带投影和复杂背景的图。

A 交付

白底 / 透明底、平光、单对象、正面或 3/4 视角、1024²+ 的角色基准图；复杂角色再补正 / 侧 / 后三视图（尺寸一致、顺序固定）。

图生 3D

轻量验证用 TripoSR（~6 GB / 亚秒级 / MIT）；中文生态与手办适配看 Hunyuan3D-2；资产级质量与干净许可看 TRELLIS / TRELLIS.2（MIT）。输出 GLB / OBJ。

修模收尾
